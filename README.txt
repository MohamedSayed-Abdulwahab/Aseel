# ASEEL — Romantic One Page Website

## Folder structure

aseel_romantic_website/
├── index.html
├── style.css
├── script.js
├── images/
│   ├── aseel-main.jpg
│   ├── story.jpg
│   ├── memory-1.jpg
│   ├── memory-2.jpg
│   ├── memory-3.jpg
│   ├── memory-4.jpg
│   ├── memory-5.jpg
│   └── song-cover.jpg
└── music/
    └── our-song.mp3

## What you need to add

Put your own photos inside `images/` using the exact filenames above.

Put your song inside `music/our-song.mp3`.

Then open `index.html` in a browser.

## Editing the text

All visible English text is inside `index.html`, so it is easy to replace with your own message.

## Notes

- The site is mobile-first.
- The Memories section is swipeable on phones.
- The music player uses a local MP3 file.
- No backend or database is required.
- No external image URLs are used.
